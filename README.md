# طابور الحلاق — صفحة التحميل

موقع ثابت (HTML فقط) يعرض التطبيق ويتيح تنزيل `barber-queue-1.0.apk` مباشرة.

## النشر على GitHub Pages
1. أنشئ مستودعاً جديداً على GitHub (عاماً Public).
2. ارفع كل محتويات هذا المجلد إلى جذر المستودع، ومنها الملف المخفي `.nojekyll`.
3. من **Settings ← Pages** اختر: Source = Deploy from a branch، Branch = `main`، Folder = `/ (root)`، ثم Save.
4. بعد دقيقة يصبح الموقع على: `https://USERNAME.github.io/REPO/`

## تحديث التطبيق لاحقاً
استبدل ملف الـAPK بنسخة جديدة بالاسم نفسه، أو غيّر اسمه وعدّل الرابط في `index.html` (ابحث عن `barber-queue-1.0.apk`).
